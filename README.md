# Personal Portfolio Website

개인 포트폴리오와 프로젝트를 소개하기 위해 제작한 웹사이트입니다.

경력 / 개인·팀 프로젝트 / 자격증 / 교육사항을 하나의 페이지에서 확인할 수 있도록 구성했으며, **HTML, CSS, JavaScript**를 기반으로 제작했습니다.

## 주요 내용

* 👨‍💻 자기소개 및 개발자 프로필
* 💼 경력
* 🚀 프로젝트 소개

  * HN SmartHome ChatBot
  * Web Visit History Visualization
  * 예약 메일 발송 시스템 (MSA, RabbitMQ)
  * hi-eating
  * hi-eating-crawler
  * Hyundai-HR
* 🛠️ 기술 스택 및 개발 경험
* 📜 자격증 및 교육 이력
* 📬 연락처 및 GitHub 링크
