# 이재우 — 개발자 포트폴리오

Java / Spring 백엔드 지원을 위한 개인 포트폴리오입니다. 실무 경력과 전체 프로젝트, 학력·교육·수상·자격·어학을 하나의 문서에서 읽을 수 있습니다.

## 로컬에서 보기

빌드나 패키지 설치가 필요하지 않습니다. 저장소 루트에서 실행합니다.

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

브라우저에서 [로컬 미리보기](http://127.0.0.1:4173)를 엽니다. 종료는 `Ctrl+C`입니다. `index.html`을 직접 열어도 콘텐츠와 탐색은 동작하지만 이메일 복사는 HTTPS 또는 localhost에서 지원하는 브라우저가 필요합니다.

## 읽는 순서와 설계

`소개 → 대표 프로젝트 3개 → 추가 프로젝트 6개 → 경력 → 기술 → 수상 → 학력·교육·자격·어학 → 연락처`

- 밝은 바탕, 짙은 글자, 초록색 포인트와 구분선으로 정보의 위계를 만듭니다.
- 프로젝트마다 해결한 문제, 기여·구현 내용, 기술과 GitHub 링크를 함께 제공합니다.
- 팝업과 이중 스크롤을 제거했습니다. 보조 프로젝트는 브라우저 기본 `details/summary`로 펼칩니다.
- 모든 이력은 HTML에 있습니다. JavaScript 없이도 탐색·상세 열기·외부 링크가 동작합니다.
- JavaScript는 현재 섹션 표시, 프로젝트 해시로 상세 펼침, 이메일 복사, 인쇄 전후 상세 상태 처리만 담당합니다.
- 인쇄 시 추가 프로젝트를 펼치고, 끝나면 독자가 열어 둔 상태를 복원합니다. PDF 저장은 일반 브라우저의 인쇄 대화상자를 사용합니다.

## 파일 구성

| 파일                       | 역할                                                     |
| -------------------------- | -------------------------------------------------------- |
| `index.html`               | 이력과 프로젝트의 단일 콘텐츠 원본, 검색·공유 메타데이터 |
| `styles.css`               | 레이아웃, 모바일 대응, 키보드 포커스, 인쇄 스타일        |
| `script.js`                | 점진적으로 추가되는 편의 기능                            |
| `assets/hwalro-system.svg` | 실제 실행 경계를 요약한 서비스·엔진 구조도               |
| `assets/favicon.svg`       | 개인 사이트 아이콘                                       |
| `docs/verification.md`     | 콘텐츠 출처와 검증 범위                                  |

Pretendard는 기존에 사용하던 버전 고정 CDN에서 가져옵니다. 로드할 수 없으면 시스템 글꼴로 표시합니다. 런타임 라이브러리, 분석 도구, 외부 스크립트는 사용하지 않습니다.

## 콘텐츠 수정

- 이력과 프로젝트 문구는 `index.html`의 해당 섹션에서 수정합니다.
- Notion 블로그가 준비되면 `#contact .contact-secondary`에 링크를 추가할 수 있습니다. 현재는 준비 중인 링크나 빈 버튼을 표시하지 않습니다.
- 교육 종료월·수상일은 확정 자료가 없어 임의 날짜를 넣지 않았습니다.
- 프로젝트의 팀 규모·기여율·성능 수치·사용자 수는 확인되지 않은 값을 만들지 않았습니다.
- Hwalro 구조도는 실제 UI 스크린샷이나 시뮬레이션 결과가 아닌 구현 구조의 설명입니다.
